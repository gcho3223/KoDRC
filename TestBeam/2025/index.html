What's New in TB2025?

Module

  • New Readout Frame: Better optical contact using spring/screw mechanism.
  • New module frame to use TB2024 only:
    • easier installation using rail & no need for SiPM setup
    • LC installed under the module for precise leakage counting.
    • New back-plane & side-planes for stability/alignment.
  • Yellow Filter: Wratten #12 → #3 (Higher light yield).

DAQ

  • Fix Timing Issue: Firmware upgrade for DAQ board
  • Move Sensor Boards: Relocated to concrete block to reduce cable tension
  • Pedestal Fluctuation: Pre-run calibration (std. dev. < ~5)
  • Separate Cables: Separated cables for adjacent modules to reduce the cross-talk
  • Trigger: New triggers with better timing resolution
