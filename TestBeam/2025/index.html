What's New in TB2025?

The 2025 beam test introduces several key upgrades in hardware design and data acquisition systems.

Module Subsystem

  • Readout Frame: Better optical contact using spring/screw mechanism.
  • TB2024 Module Only Frame:
    • Rail-based easy installation.
    • LC installed under the module for precise leakage counting.
    • New back-plane & side-planes for stability/alignment.
  • Yellow Filter: Wratten #12 → #3 (Higher light yield).

DAQ Subsystem

  • Timing Issue: Firmware upgrade for DAQ board stability.
  • Sensor Boards: Relocated to concrete block to reduce cable tension.
  • Pedestal Fluctuation: Pre-run calibration (std. dev. < ~5).
  • Cross-talk Reduction: Separated cables for adjacent modules.
  • Trigger: New triggers with better timing resolution.
