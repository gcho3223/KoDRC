Registration

CERN Registration

Before arriving at CERN

  1. Create or check your CERN account.
  2. Confirm your institute affiliation and personal information.
  3. Complete required registration forms before the beam test period.
  4. Keep your passport / ID information ready.

Dosimeter

Dosimeter Pickup Guide

  1. Check whether you need a personal dosimeter.
  2. Complete required radiation safety training.
  3. Visit the dosimeter office / service point.
  4. Bring CERN card or valid ID.
  5. Return the dosimeter before leaving CERN if required.
Dosimeter Information

Access Request

CERN Access / Beam Area Access

Request the necessary access before the beam test. The required access may depend on the experimental area, shift duty, and radiation zone.

  • Confirm required access area with the coordinator.
  • Submit access request early.
  • Check approval status before arrival.
  • Bring CERN card when entering the beam area.
Open Access Request Page

E-Pool

E-Pool Usage

  • Check the location before visiting.
  • Prepare required CERN account / access.
  • Confirm pickup and return procedure.
  • Record borrowed equipment if needed.
E-Pool Information

CERN Car / Vehicle

Vehicle Rental / Usage

  1. Check whether a CERN vehicle is needed for transport.
  2. Confirm driver eligibility and required documents.
  3. Reserve the vehicle in advance.
  4. Check pickup location, return location, and fuel policy.
  5. Report any issue immediately after use.
CERN Vehicle Page

Travel Insurance

Insurance Checklist

  • Check travel insurance coverage before departure.
  • Confirm medical coverage abroad.
  • Save emergency contact information.
  • Share insurance document with the responsible person if needed.
